# 记忆读写协议（PHYSICS-MEMORY.md）

单文件、结构化 Markdown，位于项目根目录，随项目走。

| 情况 | 写到哪 |
| --- | --- |
| 老师纠正了画法、时长、标注、风格 | 第 1 区（习惯） |
| 出现新的错误或返工点 | 第 4 区（错误档案），带日期；旧错重犯把复发次数 +1 |
| 老师要求的具体修改 | 第 5 区（修改记录），带日期 |
| 老师推翻以前的要求 | 旧条移入第 6 区并标注日期 |
| 需要老师拍板的未决项 | 第 7 区 |

写入门槛：只说「记住」或明确要求写时才写习惯；修改和错误按上面自动写；本轮没有新信息就一条不写。
隐私过滤在写之前自查一遍：账号、密码、密钥、学生信息、内网地址、绝对路径一律不写。
