# Memory store format

Location: `<home>/.physics-anim/memory/` (a global teacher profile, never inside a Git repo). Override for tests with the `PHYSICS_ANIM_MEMORY_DIR` environment variable.

## habits.jsonl

One JSON object per line:

```json
{"id": "h_<12 hex>", "kind": "presentation|communication|defaults",
 "content": "the remembered habit", "topics": ["kinematics"],
 "created": "ISO-8601", "updated": "ISO-8601", "status": "active"}
```

Rules: written only on an explicit "remember" request. Near-duplicates (normalized-content hash) update the existing record instead of appending; an exact duplicate returns "noop" and writes nothing.

## errors.jsonl

```json
{"id": "e_<12 hex>", "topic": "kinematics", "signature": "<sha256[:16]>",
 "description": "what went wrong", "correct_approach": "what to do instead",
 "recurrences": 3, "first_seen": "ISO-8601", "last_seen": "ISO-8601"}
```

Rules: written automatically when a mistake is discovered and fixed. A repeat with the same topic + normalized description increments `recurrences` and updates `last_seen` only.

## modifications.jsonl

```json
{"id": "m_<12 hex>", "topic": "kinematics", "signature": "<sha256[:16]>",
 "request": "what the teacher asked to change", "change_made": "what was changed",
 "recurrences": 2, "first_seen": "ISO-8601", "last_seen": "ISO-8601"}
```

Rules: written automatically every time the teacher asks for a modification
and the change is applied. The same topic + normalized request increments
`recurrences` instead of adding a duplicate. This is what makes the assistant
remember every requested edit across new conversations.

## deleted/*.jsonl (tombstones)

Every "forget" writes one tombstone: `{"id", "kind", "removed_at", "reason", "payload"}` where `payload` is the full original record. Nothing is silently deleted.

## index.md

Generated by `anim memory report`: habits newest-first, then mistakes ordered by recurrence count.

## Privacy filter

All writes and the `scrub` command reject: API keys/tokens, passwords, emails, phone numbers, private IPs and intranet hostnames, absolute local paths, and teacher-editable denylist words (`scripts/privacy/denylist.txt`). Violations report categories only, never the matched value.
